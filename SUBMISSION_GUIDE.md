# Submission Guide — Source Code ZIP Route

The associate guide describes two separate paths: a screenshot-heavy Word document, or a source-code ZIP. This archive is organised for the **Source Code (Zipped file)** path. That path calls for the application code base, an operational application, an architecture/flow diagram, unit-test documentation, and a ZIP without dependency folders. The 16–20 screenshot requirement belongs to the Word-document path, not the source-code ZIP checklist.

## Included
- Spring Boot Java 21 application, JPA/Hibernate entities and repositories.
- Owner-scoped Transaction API and shared-expense API.
- Equal/custom allocation and net balance calculation.
- JUnit 5 and Spring integration tests.
- Architecture text and rendered diagram.
- Copilot custom instructions, review, prompt plan, PR, tool strategy and test documentation.
- Git repository history and CI workflow (`.github/workflows/maven.yml`).

## Evidence and execution status
- The Maven test suite was **not executed in the preparation environment** because Maven is not installed and external package downloads are blocked. No passing test report is claimed.
- The included GitHub Actions workflow runs `mvn clean test` on push, pull request, or manual workflow dispatch once this repository is pushed to GitHub. The resulting Actions log and Surefire report will be genuine CI evidence.
- The untouched starting Transaction files are not included because they must be generated and saved by GitHub Copilot using the exact required prompt. See `BASELINE_NOT_GENERATED.md`.
- Copilot prompt-chain and limitation documents are preparation templates. Replace planned prompts/observations with the exact features and limitations from your real Copilot use. This package does not claim the code was generated by GitHub Copilot.

## Minimal remaining user actions
1. Replace the filename's `ASSOCIATE_ID_REQUIRED` prefix with your actual Associate ID.
2. Upload this project to a GitHub repository (or open it in Codespaces). The `.git` history is already included in the ZIP.
3. Let the included GitHub Actions workflow run and download the Surefire test report from the workflow artifacts. This executes in GitHub's cloud; no local Maven installation is needed.
4. Use GitHub Copilot Chat for the exact baseline prompt, then keep its two raw files untouched in `baseline-transaction/` and update the evidence notes honestly.

## No screenshots required for this ZIP path
The guide's approximately 16–20 embedded screenshots are for the alternate Word-document path. Do not insert random Internet/stock images as IDE evidence. `architecture.png` is a generated architecture diagram, not a screenshot and is correctly included as an architecture deliverable.

## ZIP hygiene
The package excludes `target/`, Maven caches, downloaded dependencies, `node_modules`, and IDE caches. It retains `.git/` to preserve the Conventional Commit history.
